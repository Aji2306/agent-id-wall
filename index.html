Agent ID Wall is an entry for the Binance Agent ID Hackathon. It uses your Agent ID (your on-chain .ai name) as the gate: only addresses that hold an Agent ID can post. The contract stores no names and collects nothing — names shown next to a post are resolved from the Agent ID registry or the SPACE ID API, and fall back to the poster's address. This site never asks for your seed phrase, private key, or pairing code, and never signs anything on your behalf.
